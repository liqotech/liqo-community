## Minutes

Meeting was mainly dedicated to decide how to address the first vulnerability report received on Liqo.
Main decisions:

- Turn on the proper function on GitHub, and handle that through the functions provided by the portal.
- Do not add complexity to the system (e.g., an email address about how to report vulnerabilities; skilled people know how GitHub works, hence are perfectly fine with this method).
- Add a file to document how to report vulnerabilities (SECURITY.md).
- Interact (privately) with the researched who reported the vulnerability to address it properly.
- Make a new minor release (1.3.0) as soon as the previous interactions conclude with the mutual agreement between the two parties.

Continued to review existing PR, and merging (whenever possible).
